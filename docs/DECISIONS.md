## D-5 · 2026-11-18 — KNIME 정답 라벨 (Claude 제안 · 사용자 수용)
- 주 라벨 `label_win`: 기사 +60초 뒤 첫 1분봉 시가에 진입 → 실거래와 같은 분할 규칙으로 청산 → 수수료 뺀 손익 > 0
